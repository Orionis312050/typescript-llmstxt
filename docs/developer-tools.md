# Developer Tools

Teams SDK ships with tools that simplify and speed up building and testing agents. Use the Teams Developer CLI to scaffold and manage projects, and the Microsoft 365 Agents Playground to test your agent locally without sideloading into Teams.

1. [Teams Developer CLI](./developer-tools/teams-developer-cli.md)
2. [Microsoft 365 Agents Playground](./developer-tools/microsoft-365-agents-playground.md)
3. [Local Tunnels](./developer-tools/exposing-your-local-app-with-a-tunnel.md) — expose your local server publicly for Teams, message extensions, and other webhooks
4. [Agent Skills](./developer-tools/agent-skills.md) — give AI coding assistants context for Teams development
5. [llms.txt](./developer-tools/llmstxt.md) — documentation files optimized for AI coding assistants
6. [DevTools](./devtools) (deprecated)
